# Altai Booking System

Профессиональная система бронирования для базы отдыха на Алтае, построенная на принципах ООП и SQL-хранилища. Программа автоматизирует учет гостей, расчет стоимости и защиту от двойных бронирований.

## Основной функционал:
- База данных: Полная интеграция с SQLite. Все бронирования сохраняются в файл `altai_resort.db` и не пропадают при перезапуске.
- Алгоритм защиты от овербукинга: Проверка пересечения временных интервалов на уровне SQL-запросов. Невозможно забронировать один и тот же номер дважды на одни даты.
- ООП Архитектура: Весь проект спроектирован в виде класса `AltaiBookingSystem`, что обеспечивает легкое масштабирование и чистоту кода.
- Динамическое ценообразование: Автоматический расчет стоимости с разделением на будние и выходные тарифы.
- Валидация данных: Многоуровневая обработка ошибок (формат дат, корректность интервала, наличие категорий).

## Стек технологий:
- Python 3
- SQL / SQLite3 (хранение данных и аналитические запросы)
- OOP (Object-Oriented Programming)
- Datetime API (управление временными периодами)

## Как запустить:
1. Убедитесь, что у вас установлен Python 3.
2. Склонируйте репозиторий или скопируйте файл `main.py`.
3. Запустите программу: `python main.py`.
4. Файл базы данных `altai_resort.db` будет создан автоматически при первом запуске.
