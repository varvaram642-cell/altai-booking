# Altai Booking

Система расчёта стоимости проживания на базе отдыха «Алтай».

## Возможности

- Расчёт количества ночей между датами заезда и выезда
- Разные цены для будней и выходных дней
- Выбор категории номера из списка
- Защита от неверного ввода дат (программа не падает)

## Технологии

- Python 3
- Библиотека `datetime` для работы с датами
- Конструкция `try/except` для обработки ошибок
