# Altai Booking

Это автоматизированная система бронирования для базы отдыха на Алтае. Программа позволяет пользователю выбрать категорию номера, рассчитать стоимость проживания с учетом сезонности (будни/выходные) и валидировать введенные даты.

## Основной функционал:
- **Динамическое ценообразование:** разные тарифы для будних и выходных дней для каждой категории номера.
- **Гибкая структура данных:** использование словарей для удобного управления прайс-листом.
- **Валидация данных:** встроенная защита от ошибок при вводе даты (обработка исключений).
- **Валидация логики:** проверка корректности интервала дат (выезд должен быть позже заезда).

## Стек технологий:
- Python 3
- datetime, timedelta (работа с временными интервалами)
- Обработка исключений (try/except)

## Как запустить:
1. Убедитесь, что у вас установлен Python.
2. Скопируйте код в файл `main.py`.
3. Запустите через терминал: `python main.py`.
4. Следуйте инструкциям на экране.
